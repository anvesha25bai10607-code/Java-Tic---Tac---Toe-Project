# Tic-Tac-Toe

## Problem Statement

The game of Tic-Tac-Toe is simple but logic-intensive. The aim here is to simulate this game in Java while using basic programming principles. This project translates real-world rules such as turn-based playing, board management, and checking for a winner into Java code using arrays, loops, methods, and conditionals.

## Project Scope

1. This project develops a text-based, two-player version of the game, running in the console.

2. The development covers:
   - Creating a 3x3 data structure to represent the board.
   - Building a loop to handle player switching between X and O.
   - Storing player moves using arrays.
   - Checking the board after each turn to declare a win or a draw.

3. The project uses Java's `Scanner` class for user input.

Note: This version focuses purely on the game's basic logic and does not include a GUI or AI opponent.

## Target Users

The target users are beginners and students learning Java programming.

It is designed for:

- Anyone learning Java who wants to see how loops and methods work in practice.
- Students who need a clear example of managing game state.
- Hobbyists who want a straightforward codebase that they can extend later.

## High-Level Features

### Turn-Based Gameplay
The game switches between Player X and Player O.

### Live Board Display
The board is printed after every move so that players can see the current state of the game.

### Win Detection
The program checks all rows, columns, and diagonals for a winner.

### Draw Handling
If all nine cells are filled without a winner, the program declares a draw and ends the game.

## Java Concepts Used
